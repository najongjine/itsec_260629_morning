# Mouse Lab — Three.js + A* 미로 탐험

`index.html`을 더블클릭하면 바로 실행됩니다. Three.js까지 포함한 `app.bundle.js`를 함께 두세요. 실행 시 Node.js나 서버 설치는 필요 없습니다. 외부 웹 글꼴을 불러올 수 없으면 기본 글꼴로 표시됩니다.

로컬 서버를 사용하고 싶다면 이 폴더에서 실행:

```powershell
python -m http.server 8080
```

브라우저에서 http://localhost:8080 에 접속합니다. VS Code Live Server로 `index.html`을 열어도 됩니다.

- **탐색 시작**: A*의 탐색 과정을 표시한 뒤 쥐가 최단 경로를 따라 치즈까지 이동합니다.
- **일시정지 / 계속하기**: 탐색과 이동을 멈추고 재개합니다.
- **새 미로**: 미로와 출발·도착점을 모두 무작위로 생성합니다.
- **출발·도착 변경**: 현재 미로에서 서로 다른 두 칸을 다시 선택합니다.
- **크기 / 속도**: 7·11·17·23 크기와 0.5~5배속을 지원합니다.
- 드래그로 회전, 스크롤 또는 두 손가락으로 확대·축소합니다.

`maze.js`는 반복형 무작위 깊이 우선 탐색(DFS)으로 모든 칸이 연결된 미로를 생성합니다. A*는 상하좌우 이동 비용 1과 맨해튼 거리 휴리스틱을 사용합니다. `app.js`는 Three.js 렌더링과 탐색·이동 애니메이션을 담당합니다. 3D 모델은 외부 파일 없이 코드로 만듭니다.

알고리즘 검증: Node.js가 설치되어 있다면 이 폴더에서 `npm test`를 실행하세요.

소스 수정 후에는 `npm ci`로 개발 의존성을 설치하고 `npm run build`로 `app.bundle.js`를 다시 생성하세요. 생성된 번들 및 라이선스 파일도 함께 보관합니다. 일반 스크립트로 묶어 `file://`에서 ES 모듈을 불러올 때 발생하는 CORS 제한을 피합니다.

참고: [Three.js 공식 설치 안내](https://threejs.org/manual/en/installation.html).
